## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_advertising_packages`** is the dedicated commercial tier and media sponsorship module for **UNIVERSE HUOKAING THARA Group**. It enables brands, agencies, and business partners to compare promotional packages across our multi-million-view entertainment network (Movies, Music Videos, Pranks, and Ghost Stories Khmer) and submit direct booking requests.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔄 Dynamic Billing Toggle:** Switch seamlessly between **Monthly** and **Annual** billing cycles with an automatic **20% discount** recalculation across all standard tiers.
* **📊 Side-by-Side Comparison Matrix:** Clean, responsive comparison table detailing banner placements, pre-roll video ads, sponsored articles, and account management levels.
* **⚡ One-Click Package Selection:** Clicking any tier's action button automatically populates the booking form and smoothly scrolls the user to checkout/inquiry.
* **🌐 Bilingual Interface (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or dual-language display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់
